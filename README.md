# Telegram Stickers Bot

Бот превращает видео и видеокружки в круглые видеостикеры (WebM/VP9 с альфа-каналом).

## Возможности

- Круглая обрезка со сглаженным краем, 512×512, до 30 FPS.
- Превью первого кадра до конвертации — видно кадрирование.
- Скорость с шагом 5% (−90…+900%), пересчёт длины на каждый клик.
- Обрезка фрагмента: старт и длина с шагом 0.5 с.
- Эффекты: реверс и бумеранг.
- Кнопка «Уместить в 3 с» — считает нужное ускорение под лимит Telegram.
- Добавление готового стикера в личный пак пользователя.
- Автоподбор качества под лимит 256 КБ.
- GPU-декод с откатом на CPU.

Принимает видео, видеокружки, GIF и документы с видео. Исходник до 20 МБ —
больше Bot API боту не отдаёт.

## Запуск в Docker

```bash
cp .env.example .env      # вписать токен от @BotFather
docker compose up -d
```

Логи и состояние:

```bash
docker compose logs -f
```

```bash
docker compose ps
```

Остановка:

```bash
docker compose down
```

## Запуск без Docker

Нужны Python 3.11+ и ffmpeg с ffprobe в PATH.

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

## Настройка

Единственная обязательная переменная — `BOT_TOKEN`, из `.env` или из окружения.
Остальное правится константами в начале `main.py`: лимиты стикера, шаг процентов
и обрезки, потолок длины для эффектов, лестница качества, эмодзи пака.

## Как это работает

Рабочие файлы лежат в `tmp/<код-задачи>/`, код вида `aaaa-bbbb-cccc-dddd`.
Папка задачи удаляется по завершении, отмене или по таймауту сессии; остатки
после падений подчищаются при старте.

Круглая маска и фон-шашечки для превью строятся один раз при запуске и
переиспользуются: наложение через `alphamerge` вместо попиксельного `geq`
на каждом кадре.

GPU задействован только на декоде исходника. Кодировать VP9 с альфа-каналом
не умеет ни NVENC, ни QSV, ни VAAPI, поэтому энкодер всегда `libvpx-vp9`
на CPU — прокидывать GPU в контейнер имеет смысл только под тяжёлые исходники.

## Ограничения Telegram

Видеостикер: до 3 секунд, до 256 КБ, 512 px по стороне, VP9, до 30 FPS.
Бот не режет видео принудительно — если результат не проходит по лимитам,
Telegram отклоняет отправку, и бот присылает готовый `.webm` файлом,
предлагая ускорить или обрезать.
